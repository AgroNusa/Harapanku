# Harapanku — Pediatric Growth & Therapy Clinic Digital Platform

Platform digital modern dan terpercaya untuk **Klinik Tumbuh Kembang Anak Harapanku** di Balikpapan, Kalimantan Timur.

---

## 🌟 Fitur Utama

- **Zero Waiting List Booking:** Komitmen penjadwalan asesmen awal cepat dalam 1–3 hari kerja.
- **Frictionless WhatsApp Intake:** Pendaftaran 4 isian wajib yang langsung terhubung dengan pesan terformat rapi ke Care Coordinator klinik.
- **Transparansi Digital (Parent Dashboard):**
  - **Milestone Radar:** Pemantauan progres wicara, sensori, motorik, dan kemandirian anak.
  - **Daily Therapy Log:** Catatan evaluasi langsung dari terapis berlisensi (STR Kemenkes).
  - **Monthly Target Checklist:** Daftar pencapaian target bulanan interaktif.
- **Layanan Klinis Terintegrasi:**
  - Asesmen Awal Komprehensif (90 menit)
  - Terapi Perilaku / ABA (60 menit)
  - Terapi Wicara / Speech Therapy (45 menit)
  - Terapi Okupasi / Sensori Integrasi (60 menit)
- **Fasilitas Ramah Anak & Terapeutik:** Ruang Sensori Integrasi, Ruang Terapi Wicara kedap suara, dan Ruang Observasi/Konsultasi Orang Tua berstandar medis.
- **Desain Ramah & Aksesibel:** Dibangun dengan Tailwind CSS, tipografi ramah anak (*Poppins* & *Nunito*) serta data tajam (*Inter* & *Plus Jakarta Sans*).

## 🚀 Cara Menjalankan Secara Lokal

Cukup jalankan web server statis di folder root proyek:

```bash
# Menggunakan Python
python3 -m http.server 4321

# Atau menggunakan Node.js
npx serve .
```

Buka peramban di `http://localhost:4321`.
